# Talk track — Domain search without authentication (2–3 min)

Spoken script for JJ’s LinkedIn camera walkthrough. Issue-first. Pain and value only.  
Stage directions in `[click]` / `[say]`. Prices on screen are illustrative demo figures for the story.

---

## Open (≈15s)

[say] Enterprise agents hit a quiet wall: they need a domain name — and the first API call asks them to sign up.  
Just to check if a name is possible.

[say] Vercel just opened public domain discovery. Keyword CLI, batch API — no token to search. Auth stays where it belongs: when you buy.
